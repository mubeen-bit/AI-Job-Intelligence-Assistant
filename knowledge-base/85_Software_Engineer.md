# Job Title: Software Engineer

## Job ID: 85

## Description
Responsibilities
Develop functional and design specifications for server components of system management solution. These features and capabilities range from appliance management, configuration, HA cluster formation, bring-up of various management services, synchronize services' state across controllers in a cluster, manage bring-up of embedded database, ensure security capabilities are adequate.
Develop server components in Java and related technologies.
Analyze the performance characteristics of back-end modules. Identify inefficiencies and bottlenecks. Propose, implement and test fixes.
Create implementation and test plans. Develop software and implement test cases according to these plans.
Ensure that work is completed on time to meet the business requirements by following procedures for source code control, unit testing, end-to-end testing, and design documentation
Ensure the stability and scalability of new features and the interoperability with pre-existing system architecture. Collaborate with other developers to select appropriate design solutions.
Communicate effectively with individuals of varying technical abilities and professional backgrounds
Qualifications
Master’s or Bachelor’s degree in Computer Science, Mathematics or similar field.
4+ years of development experience designing and implementing web based backend components in JAVA.
Strong working experience with Linux OS, OS creation and configuration of packages, such as Tomcat, databases such as Postgres.
Strong knowledge of platform management, device configuration and management for both physical and virtual appliances.
Outstanding skills with Java and Script development in Linux development environment.
Strong system level knowledge of building databases, OS, OVF, Tomcat, libcurl, SSL technologies.
Prior experience of using APIs and developing APIs of different kinds including REST
Prior experience in Storage, Network, and/or System Management is a plus.
Development experience designing and implementing backend components in Go is a plus
Excellent verbal, written, and communications skills
Ability to handle multiple concurrent activities and have a flexible, positive attitude
