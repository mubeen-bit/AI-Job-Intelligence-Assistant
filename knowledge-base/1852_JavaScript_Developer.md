Responsibilities will include implementing visual elements and their behaviours with user interactions. You will work with both front-end and back-end web developers to build client-server logic. You will also be bridging the gap between the visual elements and the server-side infrastructure, taking an active role on both sides, and defining how the application looks and functions.
