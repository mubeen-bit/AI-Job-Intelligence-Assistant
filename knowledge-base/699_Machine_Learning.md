# Job Title: Machine Learning

## Job ID: 699

## Description
Who You'll be:
Write applications using dotNET; learn new stacks and technologies and apply our instrumentation to these applications.
Help customers instrument, monitor, and debug their large multi-tiered complex applications.
Replicate customer environments and work to identify & fix the root cause or provide interim workaround as needed.
Provide advanced technical support and work with customers to solve complex issues with the product in their environment.
Build internal and customer-facing Tools and extensions.
Identify product bugs and enhancements based on customer environments and work to close them.
About Team:

As a Software Engineer on the .NET Engineering team, you will be responsible for solving complex technical challenges in customer environments and working with customers to provide advanced technical support, analysing both AppDynamics and customer code. You bring experience as a hands-on software engineer who can quickly scan and write code, spot bugs and resolve them, and someone who has great customer-facing communication skills. In this position, you will be responsible for building multi-tiered applications using various .NET Full/Core frameworks, asynchronous programming patterns, and cloud components. You’ll be working in customer environment as well as Cloud environments such as AWS and Azure. This is a unique opportunity to work in a rapidly-scaling, fast-paced environment with exposure to the most advanced technologies across the stack.

Who you're:
Min of 3+ years of software development experience in .NET with extensive debugging and troubleshooting.
BS in Computer Science or equivalent work experience
Experience is configuring IIS, Docker, AWS, Azure, and Windows networks.
Experience with object-oriented and asynchronous programming patterns
Understanding of MVC design patterns and frameworks
Real-world experience coding/deploying/troubleshooting .NET Core hosted in Docker Linux containers, Windows, and Cloud environments.
Knowledge of Web protocols, formats, and server environments
Outstanding attention to detail, specification, and ability to troubleshoot/fix complex problems in customer environments.
Proven customer-facing professionalism with great communication skills; IE the ability to tailor communication for the audience. You’ll be working with very technical, as well as some non-technical customers.
