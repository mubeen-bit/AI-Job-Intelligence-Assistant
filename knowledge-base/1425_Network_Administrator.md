# Job Title: Network Administrator

## Job ID: 1425

## Description
Key Responsibilities:
respond to requests for technical assistance in person, via phone, electronically
diagnose and resolve technical hardware and software issues
research questions using available information resources
advise user on appropriate action
follow standard help desk procedures
log all help desk interactions
administer help desk software
track and route problems and requests and document resolutions
prepare activity reports
stay current with system information, changes and updates
Technical Skills/Competencies Required:
Must have proficient knowledge in the following areas:
· Configure and Maintain Secure FTP Server, Setup and maintain Test environment (web server and database server).
· Install, maintain and support User-end devices such
as Desktops, Laptops, Printers, Plotter, Scanner Data
and Voice Network, etc.
· Manage (Configure, Troubleshoot) Windows XP/7
clients & Windows 2000/2003/2008 Servers
· Manage Windows 2003/2008 Active Directory Domain
Network (DNS, DHCP, DFS, Group Policies)
· Manage shared folder access rights
· Manage Local Area Network (wired & wireless)
· Knowledge on VLAN
· Manage Firewall (security policies, VPN tunnels)
· Install, maintain and support Data and Voice Network, IP telephony and voice recording solution
· Install and maintain server hardware and assist in
System Administration activities and support Unix,
Linux, Windows Operating systems to keep up with the
latest technology.
