# Job Title: iOS Developer

## Job ID: 452

## Description
Bytemark is looking for a talented iOS Developer to work as part of our team in Bangalore.

Job Description:
The iOS Mobile Developer maintains, manages, and continually develops a suite of applications built for our top clients. Coordinate and participate in the implementation, testing and support of iOS-based applications using Objective-C, Cocoa, Xcode and the iOS SDK. Design and implement new features, create UI, debugging and data modeling. Assist in testing all applications against software and hardware versions. Provide timely turnaround and documentation of bug fixes during test cycle.

Duties:
Provide iOS development services for BM and its clients. As an engineer on the iOS app team, your responsibilities will range from high-level user interfaces, to writing networking code to communicate with web service APIs to developing framework code used by other teams at Bytemark and third party developers. You'll be responsible for maintaining and improving existing apps and implementing new and innovative features for future apps. You will also be responsible for debugging and delivering the best possible application performance including smooth scrolling and delivery of on time, speedy launch times.

Qualifications:

3+ years building complex applications for iOS using Objective-C/C++ with Cocoa and other
frameworks
4+ years mobile application development at the user interface and system levels
2+ years leading a small team of developers with your role being the primary hands-on developer
Ability to understand and debug large and complex code bases
Expert knowledge of iOS SDK performance tools and optimization techniques
Demonstrated problem solving and communication skills with great experience extracting requirements from customers and translating them into features
Git experience is preferred
Shipped multiple iOS titles and can provide samples of deep, highly functional apps.... no one-trick ponies
B.S. or M.S. Computer Science or related field
Proficient in Objective-C
Knowledge of compiler settings
SQLite experience is preferred
Experience with creating static libraries is preferred
Must have a good working knowledge of UIKit
Must have an understanding of blocks, Grand Central Dispatch, and when to use each
Must have worked on an app in the App Store
Must know how to use Instruments (Leaks, Object Allocations, etc)
Must know good memory management techniques (what goes in dealloc, viewDidUnload)

Company Description:
Bytemark, Inc. develops highly customized applications in the mobile space. We offer ticketing solutions across the security spectrum.
