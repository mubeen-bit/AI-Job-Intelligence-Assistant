## Description
STP provides Fund Administration and Performance Consultancy services to Global Investment Management Firms and Mutual Funds worldwide. STP intends to set new quality standards in a competitive environment, to help attract and retain a blue-chip client base.
The job holder primarily role is to gather requirements, analysis, develop, implement, test software applications using Microsoft Technologies in asp.net/MVC/Jquery/Json/SQL. The candidate will also involve in project management, weekly status management. The candidate will maintain accuracy level set by client and deliver within SLA agreed by client.
The candidate will be proactive in interfacing with client and other functional areas. Any queries related to project must be escalated to the respective Manager.
