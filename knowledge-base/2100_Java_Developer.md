# Job Title: Java Developer

## Job ID: 2100

## Description
Responsible to perform software development for internal web-based and other ES3 software projects, US Air Force projects and in support of ES3 engineering projects in a team-oriented work environment. Demonstrate ability to use software development best practices in activities such as requirements analysis, design, coding, software configuration management, documentation and testing. Must have the ability to effectively work independently and within a team. Must be able to problem solve and be self-motivated. Must be able to interact with management, engineers, subcontractors, team members and customers in a professional and collaborative manner.

Design, coding and testing of web-based and other software applications

Perform other duties as requested

C#, ASP.NET

HTML, CSS, JQuery and Javascript
RDBMS via MS SQL Server
Technical Writing
XML
Windows
Subversion

Familiarity with CMMI a plus.

Education and Experience Required

Bachelors Degree (Computer Science)
Minimum 4+ years of related experience

Ability to travel if required.
