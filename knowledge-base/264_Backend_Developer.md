# Job Title: Backend Developer

## Job ID: 264

## Description
Job Location: Panchkula, Haryana || Remote Work
Job Summary:
We’re looking for a Back-End Developer who specializes in server-side components. In this role, you’ll primarily work in Node.js and will bring a depth of knowledge on basic algorithms and data structures.
As a Back-End Developer, on any given day you might be designing new features for our customers, refactoring existing code to be more scalable, debugging, API optimization, requirements analysis, feature estimation, and seeing changes through to completion in a live environment.
Job Responsibilities:
Work as part of a team developing applications and services using Agile development methods.
Effectively use tools and ingenuity to identify and fix defects before they become a problem.
Design, build, and configure applications to meet business process and application requirements.
Good Hands-on experience in Node Js frameworks like Express, Hapi, and other Javascript frameworks like Socket.io.
Knowledge and understanding of Request, Response, and proficiency in REST-ful APIs.
Implementation of security like OAuth 2.0, OAuth 1.0, JWT, Basic Auth, and data protection.
Integration & Design of data storage solutions like RDBMS, NoSQL DB, MySQL, MongoDB, Redis and dynamoDB etc.
Experience in combining and implementing analytical and creative problem-solving techniques and approaches.
Maintain high standards of software quality within the team by establishing good coding practices and habits.
Knowledge of code versioning tool - Git.
Good knowledge of Unit Testing and available Test Frameworks.
Good to Have:
Basic understanding of front-end technologies, such as HTML5 and CSS3, Bootstrap 4.
Understanding of frontend frameworks like ReactJS, Angular, VueJS.
Understanding differences between multiple delivery platforms, such as mobile vs. desktop, and optimizing output to match the specific platform
