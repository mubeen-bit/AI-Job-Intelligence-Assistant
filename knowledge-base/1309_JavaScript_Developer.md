# Job Title: JavaScript Developer

## Job ID: 1309

## Description
Job Role:

The role is targeted at candidates with 2 to 6 years of experience in front-end/GUI development of Web Applications in JavaScript/jQuery and Java. The developer would work with the product team in designing the front-end layer of applications while developing middle layer to enable client-server communication.

Responsibilities:
Work with the products team in designing UI of cloud-based products
Work on client-side and server-side programming to incorporate functional specifications.
Integrate third party libraries to design UI components such as grids, drag and drop dashboards, graphs, real-time charts, reports etc.
Develop custom reports, interactive UI components based on client expectations.
Work with the backend team in creating the appropriate data exchange interfaces (APIs) between database/analytics servers and our application server.
Ideal candidate:
Expertise in jQuery, JavaScript and JSP – Mandatory
Expertise in Bootstrap, CSS 3, HTML5 – Mandatory
Experience in JSON and REST API – Mandatory
Experience in Core Java – Mandatory
Good to have experience/exposure in Spring MVC, MSSQL and chart libraries
Good to have experience in cloud applications – preferably MS Azure
2 to 6 years of front-end development of enterprise applications
What we offer?
A competitive salary. You grow with us.
A non-hierarchical, entrepreneurial and exciting work environment.
We focus on the deliverable and not on the hours of work you put.
Expand your functional knowledge across areas in Supply Chain and expand your skills into building cloud based applications for global clients.
