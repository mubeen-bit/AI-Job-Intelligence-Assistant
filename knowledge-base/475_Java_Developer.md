JOB Title: Senior Developer

COMPANY DESCRIPTION:
SAP Ariba is the world's business commerce network. We help companies extend their business commerce processes into the Cloud, where they can use our Procurement solutions and the Ariba Network to find opportunities to cut costs, reduce risk, and grow revenue through better collaboration with trading partners. The Ariba Network is the world's largest trading partner community with more than US $1 Trillion in transaction volume flowing through and more than 1.7 million businesses in 190 countries around the world trading in 172 currencies.
The Supplier Management solution is built on a robust highly scalable cloud platform that helps businesses integrate with the rest of organization's procurement processes, it's the only end-to-end solution portfolio that lets organization's manage supplier information, lifecycle, performance, and risk all in one place.
We are presently looking for engineers to work on this highly scalable and complex platform and modern User Interface with function rich features and Rest based open API integration capabilities. This plays a key role in our vision for high frequency production releases with high quality.

THE ROLE:
• Work in multiple components of Supplier Management building on robust, easily deployable componentized Micro service architecture and existing tried and tested platform.
• Troubleshoot and solve Complex Cloud Scalability issues
• Develop/Enhance the user experience using newer technologies like AngularJS
• You will be member of the core Ariba Supplier Management team in Bangalore, Ariba IDC which is one of the biggest engineering teams in Ariba globally

ROLE REQUIREMENTS:
• Bachelors in computer science or equivalent work experience with minimum 8+ years of development experience developing production grade software
• Strong java programming skills, as well as the ability to read and code review complex code bases written by others
• User Experience technical design and architecture using Web technologies that includes implementation with AngularJS
• Enterprise J2EE architecture and design expertise including prior Server side implementation experience.
• Demonstrated leadership and ownership of a medium and innovative feature that has been successfully deployed
• Experience in a Cloud based development environment
