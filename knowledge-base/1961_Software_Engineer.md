MS/BS in Computer Science/Computer Engineering or related field of study with 3+ years of relevant experience
Knowledge of file systems, storage and cloud technologies, emerging standards and engineering best practices

Solid knowledge of algorithms and design patterns
Mastered the fundamentals of programming and/or debugging skills in C++, C #, and/or Java, Javascripts and AngularJS
Skills in scripting languages such as Perl, Python or Ruby on Rails
Working knowledge of API fundamentals and best practices
Skills with Office Application Suite Microsoft Access, Excel, Word, PowerPoint and Visio, both in use and automation
Knowledge of databases and SQL
Knowledge of operating Systems: LINUX/UNIX· Object Oriented Language· Agile Process
Strong problem solving and organizational skills
Desired skills include:
Knowledge and experience with Python and other scripting languages
C/C++/Java programming skillset
Experience in Agile development methodologies including unit testing and TDD (test-driven development)
