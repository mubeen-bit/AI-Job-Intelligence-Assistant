# Job Title: Network Administrator

## Job ID: 1882

## Description
Roles and Responsibilities
Managing and providing level 2/3 support to network and security setup of customer on site
Administer and manage the network and security assets across the companies.
Network Setup includes network architecture, switching and routing, firewalls, Email Security, URL Filtering.
Designing solutions and actively monitoring and managing major change activities.
Performing all devices monthly health checks, scheduling, issue remediation if any, and reporting to senior management.
Investigate and help resolve issues on the customer's network and IT estates using agreed troubleshooting methodologies.
Troubleshooting, diagnosing, and resolving hardware, software, and other network and system problems
Replacing faulty network hardware components when required
Plan and execute the in-depth technical activity, influencing the direction of activities/plans and providing technical insight and guidance to others.
Conferring with network users about solving existing system problems
Interacting with customer for any technical requirement or discussions over advanced technologies and solutions
Work closely with team members to provide quick support & error free environment in close cooperation
Qualifications
Bachelors in Information Technology
Fluent English
Strong experience in Cisco Security Technologies like Firewall, Firepower, VPN, AAA, ISE and Routing & Switching
Expertise in troubleshooting complex network and security related issues.
Should be able to support Cisco ASA firewalls, Cisco Identity Services Engine (ISE), Cisco Wireless controller, Tipping Point IPS, Fortinet Firewall and A10 load balancers
CCIE Security is mandatory.
Customer-facing experience is mandatory.
Good communication skills and the ability to convince and build social relationships.
Ability to work with a multi-functional and geographically diverse team is expected.
Solve problems creatively and multi-task in a fast-paced and rapidly evolving environment.
