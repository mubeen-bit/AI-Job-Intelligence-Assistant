# Job Title: Software Engineer

## Job ID: 1989

## Description
Full Stack Developer

Position Summary

We are looking for an experienced full-stack developer, a team player who's passionate about technology, learning and problem solving.

You will join our UI team, owning end to end responsibility for our web platform and infrastructure, and be involved in building our roadmap by researching product behavior and usage.

We’re working in a fast-paced environment, daily shipping new features and improved infrastructure, working closely with all teams across the company mainly the product, data, DevOps and QA teams.

Role and Responsibilities
Design, code and manage our web platform using industry best practices focusing on quality, performance, and delivery.
Write well-crafted, well-tested, readable, maintainable code.
Make sure our team’s development effort fulfills its purpose, taking our product and infrastructure to the next level.
Participate in code reviews, evaluate implementations and provide feedback to ensure code quality and distribute knowledge.
Job Requirements

At least 3 years of experience in UX/UI – must!

Experience both in Frontend and Backend development

Excellent understanding of Angular7 framework, TypeScript, Node.js, npm, HTML5/CSS3/ECMAScript6.

Experience with cloud and multi-tenancy development.

BSc. in Computer Science or equivalent.

Experience in the AngularJS (Advantage).

Experience as web architect (Advantage).

Experience with Java/J2EE server side development, Spring Web MVC (Advantage)

Familiarity with WCAG best practices. (Advantage)

Excellent communication skills.

Experience with scalable API based agent or service oriented software architecture.
