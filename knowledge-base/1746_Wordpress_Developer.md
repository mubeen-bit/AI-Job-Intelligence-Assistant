Job Description

We are looking for a talented WordPress developer who knows WordPress inside out. The candidate must be passionate about creating high quality wordpress websites, themes and plugins. The developer will work closely with our project management team, designers and other developers.

Job Role
Develop high-quality responsive WordPress websites.
Code WordPress plugins from scratch.
Modify themes and plugins as per requirements.
Enhance & fix bugs in existing wordpress sites and plugin.
Integrate various third-party APIs.
Security evaluation and code optimisation for improved website load time.
Requirements
B.tech/BE/MCA/Graduate or Equivalent qualifications in Computer Science.
Strong experience (1 to 5 years) in Core PHP 7+ with MySQL and other DBMS.
Deep knowledge of WordPress CMS and its popular plugins, themes
Well verse with HTML5/CSS3, Javascript, jQuery and AJAX.
Excellent knowledge of OOPs, data structures, SDLC, HTTP and RDBMS.
Should be good in developing the algorithms for complex problems.
Knowledge of web development processes, XML Structures, Session & Cookies Handling and Version Control.
Knowledge in one or more other CMS like Magento, Drupal, Shopify, CraftCMS etc is a plus.

Knowledge of server commands, web servers, migration of servers, etc to carry out the project. Knowledge on AWS is an added advantage.
Can understand client’s requirement & functional specifications and propose the solutions.
Writing clean, reusable code with strong emphasis on stability, security and performance.
Delivering on time and according to requirements.
Proactive person who can take ownership and meet the deadlines.
Excellent problem-solving and testing skills.
Can adapt new skills as per the project’s need.
