# Job Title: DevOps Engineer

## Job ID: 1683

## Description
Job Summary

We are seeking a DevOps Engineer who is passionate about building complicated workflows and maintaining a variety of different networked systems. The right candidate will interact with stakeholders across Engineering, QA, IT, Operations, and Marketing.

Job Duties
Work with both development and QA teams with a focus on automating builds and deployments
Design and develop a continuous deployment pipeline, integrating GitLab, Jenkins, and Docker for a variety of server types
Implement CI/CD in projects (GitLabCI)
Source Code Management (SCM) using tools, e.g. Github (with Git workflows)
Enable software build and deploy using tools such as Jenkins, Maven, Elastic Container Service, Lamba, Docker Repository
Write, plan, and create infrastructure as a code
Monitoring, ITSM automation incident creation from alerts
Build system status reports
Ensure team collaboration using Jira, Confluence, and other tools
Build environments for unit tests, integration tests, system tests, and acceptance tests
Maintain and administer Jenkins systems

Excellent oral and written English communication skills
