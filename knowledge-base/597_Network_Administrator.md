# Job Title: Network Administrator

## Job ID: 597

## Description
Is managing large networks and building data centers your cup of tea? Then you will thrive and grow with our IT team. We are looking for IT rock stars with a zeal to become IT managers and Senior consultants. You will build new IT infrastructure from the bottom up.
Responsibilities
Windows and Linux systems, business applications, anti-virus protection, email and authentication administration.
Perform software and application development, installation, and upgrades.
Plan and implement network security, including building Firewalls, managing host security, file permissions, backup and disaster recovery plans, file system integrity, and adding and deleting users.
Evaluate and/or recommend purchases of computers, network hardware, peripheral equipment, and software.
Install, configure, and maintain workstations, file Servers, Ethernet networks, network cabling, and other related equipment, devices, and systems; adds or upgrades and configures modems, disk drives, data acquisition boards, CD ROM units, printers, and related equipment.
Troubleshoot networks, systems, and applications to identify and correct malfunctions and other operational difficulties.
Network administration (including backup, security management, user account management, e-mail systems including e-mail web server, Internet access, office systems and applications support).
Supports server, network and desktop hardware, software and applications.
Plans, implements, and supports the network and computing infrastructure plan.
Manages small to medium sized projects according to agreed upon budgets and schedules.
Network Infrastructure design and troubleshooting; WAN and TCP/IP administration; Software/Hardware, testing, maintenance, support; and advanced end-user support.
Ability to identify and resolve computer system malfunctions and operational problems.
Ability to provide technical training to end users and learn and support new systems and applications.

Platforms/Applications
Linux, ClearOS, Windows Server 200x, Windows XP to 7, VMWare, MS Office, MS Exchange, Tally , PeopleSoft or any ERP system, LAN/WAN, WMS systems, Microsoft SQL support
Minimum Qualifications
2 year Associate’s Degree
4+ years experience PC and network support experience in a Unix/Microsoft environment.
Computing and network hardware and peripheral equipment.
Knowledge of computer and/or network security systems, applications, procedures, and techniques.
Windows Servers and desktop products.
Demonstrated ability to administer a 250+ node network including Firewalls.
Demonstrated ability to support networked printers and photocopiers.
Preferred Qualifications
Any Graduate with completion of echnical courses like GNIIT (which involves more than 1 years of technical training), MCSC,/MCSE, MCP, Red Hat Certified RHCE, VCP etc.
Experience with ClearOS, SAN/NAS.
Experience with Cloud based networks.
Minimum 2 years experience as Windows Systems Administrator
Minimum 2 years experience as a Linux Systems Administrator
Supervising or training juniors, and being the consultant for computer problems beyond the knowledge of technical support staff.
