# Job Title: Java Developer

## Job ID: 1508

## Description
_Apply your C#, _Java,_ and/or JavaScript server skills to build next-generation back-end systems that __improve the health, well-being, and security for millions of people. Grow your current skills and learn new ones as you partner with industry thought leaders, system architects, front-end developers, and a supportive QA team. _

We are seeking skilled server developers who can enthusiastically build next generation FinTech and IoT software to improve health, well-being, and security that will benefit millions of peoples. Candidates should be passionate about coding robust, reliable, and scalable products. The ideal candidate will demonstrate expertise with server-based development using .Net and Java and ideally with additional technologies including Node.js, PHP Laravel and C++.

Experience with team-based development using agile principles, Jira and git will be very helpful. Strong communication and collaboration skills will be essential. The candidate should be knowledgeable on current technologies and able to share new ideas and energy with the team and our customers.

Your Position*
You will participate in requirements gathering, technical design, agile development, and customer interactions. You will apply your existing skills while staying abreast of the latest trends and tools. Most deployments will be cloud-based, but there is no “one size fits all” for every project. You will be expected to think through the gray areas of requirements and work with the team to map out a clear path for project success.

Required Skills and Experience

• C# and/or Java language expertise, including using generics

• Experience designing and developing building RESTful APIs

• Hands-on experience with messaging-based architectures using JMS, MQTT, etc.

• JavaScript (Node.js), PHP and C++ server development skills also highly desirable

• Understanding of networking principles, including the OSI model and the use of Wireshark

• Ability to conduct UML and database modeling

• Organized, detail oriented, and a proven ability to troubleshoot

• System-level architecture and documentation experience

• Requirements documentation and traceability experience
