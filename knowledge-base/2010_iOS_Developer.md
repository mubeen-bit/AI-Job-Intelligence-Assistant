# Job Title: iOS Developer

## Job ID: 2010

## Description
We are looking for an experienced iOS developer with an eye for great design and the flair to produce great iOS apps.

Responsibilities:

Work with our designers to produce user interface and workflows in an app

Team up with peer developers and write good ObjectiveC / Swift code to implement & release features

Send daily builds to stakeholders and gather feedback

Be creative in using Xcode and related tools to deliver code faster

Take ownership of the apps you built & maintain them by following software engineering best practices

Requirements:

Minimum 2 years of iOS development experience - having shipped at least one iOS app

Proficient knowledge in ObjectiveC / Swift & iOS SDK

Proficiency with latest Xcode

Keen interest / experience in building apps with React or React Native

Experience with CoreData

Experience in creating apps that consume REST API services

Experience in making / maintaining universal iOS apps

Working knowledge in Git / Mercurial

Experience with Core Graphics and Core Animation APIs

Experience building SDKs using any language (optional, you get bonus points for this!)

Experience in designing UI prototypes using Sketch / Photoshop (optional)

Experience in using Origami and other UX prototyping tools (optional)
