# Job Title: Machine Learning

## Job ID: 1023

## Description
Summary

The Gas, Power, and Energy Futures (GPE) team at IHS Markit is seeking an individual with deep technical skill sets to assist the data science lead in developing the capabilities of our data science team. Prospects must have strong python and SQL experience, familiarity with AWS cloud computing tools, and a demonstrable academic and/or applied knowledge of data science. Individuals with some knowledge or experience working in electric power or gas markets in any country are preferred.

Core Responsibilities

Assisting the data science lead with a wide variety of tasks to further the role of data science in producing actionable insights for researchers within GPE.

Maintenance of existing data science platforms within GPE
Evaluating, testing, repairing, and improving existing machine learning models
Building tools to dynamically evaluate model quality, model drift, data quality
QA and maintenance of all associated datasets and pipelines on diverse platforms including the IHS Markit Datalake
Quickly diagnose and respond to client questions about the product
Scoping client feature requests and the product roadmap
Development
Build new big data modeling tools to support internal research, consulting activity, and new or existing products
May include both optimization models and statistical or machine learning models.
Expand existing products and analytics with new data streams, analytical layers, and interfaces
Exploratory Data Analytics
Maintain active knowledge of scope of GPE (and broader ENR) data collection activities
Continuously explore opportunities for new products from interactions between these datasets
Build novel or functional data interfaces and views for research teams to promote insights for clients
Conduct exploratory data analysis (distributions, cleanliness, statistical tests) on all large GPE datasets.
Ancillary Responsibilities

Assist Researchers
Assist research team with transition and modernization of data infrastructure around existing internal analytical models
Onboard and support researchers migrating to cloud solutions and new technologies
Rebuild legacy research models to run on cloud infrastructure
Work with researchers to understand data volume and structuring challenges to bring more data into GPE and the AWS cloud platform
Build Capabilities
Contribute to the expansion of data capabilities within GPE
Work with the GPE PD&D team to scope and maintain cloud computing resources, data pipelines, and cloud architecture to support data science enabled research
Continuing education in data science tools and methods
Required Knowledge and Skill sets
Applied or academic knowledge of statistical modeling, stochastics, machine learning, and neural network models
MS/PhD in Mathematics, Computer Science, Computational Engineering, or related field
OR 5+ years experience working directly in applied data science
Portfolio of projects or work in this field demonstrating strong aptitude in the technical skillsets below in either case
Some applied or academic knowledge of optimization modeling and simulation
At least one example of applied work in this field demonstrating technical aptitude
Advanced knowledge of Python 3
Git bash and embedded git interfaces
Pyspark, numpy, pandas, ODBC, matplotlib or similar
API interactions using html and json libraries
Optimization libraries
Advanced knowledge of SQL
Particularly T-SQL and PostgreSQL, or any ANSI SQL language
Functional experience with statistical models written in R Experience working in an AWS cloud environment
Particularly Sagemaker, S3 I/O, Elastic Compute, Terraform
Strong data visualization skills including experience with PowerBI Strong time series data skills including demonstrated experience collecting, cleaning, and transforming large volumes of data efficiently using dataframes and lazy evaluation engines. Experience working with cloud analytics engines (Spark) and software libraries for large scale cloud computing (Hadoop).
Preferred Skills
Experience with or knowledge of the operation of electric power and/or natural gas production, storage, and transportation systems.
Experience with or knowledge of the structure of North American power and gas markets
Some experience with statistical or mathematical computing environments like Matlab, Julia, or E-views
Experience working with Snowflake
Experience using Azure Dev Ops or working with agile software development tools.
Exposure and aptitude with optimization software environments (GAMS) and solvers
Experience visualizing data with R-shiny, d3.js, or other python based tools.
