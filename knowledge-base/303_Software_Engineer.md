# Job Title: Software Engineer

## Job ID: 303

## Description
Job Summary: We are looking for highly skilled Java/Python/Scala/UI developers to implement coding in Cienas NextGen NMS system i.e BluePlanet MCP. BluePlanet MCP is Cienas domain controller, automating lifecycle operations of Cienas packet and optical networks. Based on Microservices architecture, MCP helps network operators to Plan, provision, and turn up multi-layer services quickly using a highly intuitive interface. MCP marks a strategic shift from legacy network management software, enabling the transformation to open, scalable software control that easily integrates into network operators Billing and Operations Support Systems (B/OSS) and Orchestration layers using open REST APIs.

Roles and Responsibilities: As a software developer, you would be involved in following
Understanding of requirements from Product Owners/Architects representing various domains and components of MCP
Working on HLD/LLD of the MCP Release features
Quick Prototyping using newer technologies and open source platforms in Web and NMS domains
Coding various components of BluePlanet MCP Software in Java/Scala/Python/UI
Create Automated Test Suites for executing test automation of your features
Troubleshooting product issues found in System Integration Testing and Customer deployments.
Mandatory skills:
3+ years of Software Development Experience in Python/UI involving Web Technologies.
Excellent understanding of Data Structures and Multi-threading concepts.
Excellent troubleshooting/debugging skills.
Excellent Problem-Solving skills.
Excellent Communications skills.
Preferred Skills:
Working experience in NMS/EMS based Softwares.
Exposure to Microservice Architecture based platforms and REST based APIs.
Understanding of Protocols and Infrastructure in Packet (Layer2) Domain i.e MPLS, G.8032, QinQ
Exposure to Elastic Search and Cassandra databases
Exposure to Apache Kafka stream processing platform
