# Job Title: JavaScript Developer

## Job ID: 695

## Description
Join our NSX User Interface team as an UI architect. We are looking for UI experts/architects who are passionate about building modern User Interfaces. Ideal candidate should be a full stack developer and have extensive real-world experience with web-based user interface technologies, write high-quality UI code, and demonstrates principles of good UI design and usability. In this role, youll be responsible for building and maintaining UI architecture, common components, and features. As an UI architect in the team you should have high standards for code , quality and also encourage best practices in the team.

NSX User interface team is charted with developing best in class UI for NSX-T product and its various feature set. The team is responsible for developing user interfaces which are 'Simple' to use, 'Modern' and 'Efficient'. We are a close knit team and believe in team work and work very collaboratively. NSX-T is redefining the way networking is done and this is your chance to be on the journey and influence the way networking is be presented to users through the User Interface.

Primary responsibilities include :
Candidate should be very hands on and independently work in the areas of
UI architecture and design
Features
Usability and Quality of features
Participate and influence architecture and design of the NSX Manager UI.
Independently design and implement framework components in NSX Manager UI.
Act as feature/module owner for features in the NSX Manager UI and deliver high quality of work.
Interact and work with cross functional teams like Product management, API teams, Usability, QA, Documentation and Release Engineering
Collaborate with other teams during both design and development phases to ensure adherence to UI architectural standards and best practices
Partner with other architects to continue to drive the development of a modern user interface layer
Document standards and ensure they are adhered to.
Provide technical guidance to other members of the team.
Evaluate and provide suggestions from time to time on developmental and testing practices. Provide technical oversight and perform code reviews.
Qualifications:
Prior experience in architecting enterprise UIs.
Extensive UI development and someone who has seen the evolution of UI technologies.
Experiences in one or more of the JS frameworks : Angular, Bootstrap, React, VUE etc.
OO Design & Development
Knowledge about common user interface patterns, MVC, REST, Partial Page refresh, DOM Traversals, Asynchronous nature of applications etc.
Experience building Visualization, Dashboards.
Experience building highly scalable and performant systems.
Working knowledge in UX design : Interaction, Layout
Strong computer science fundamentals.
Should be passionate about developing UIs and front-end systems, also possess strong sense of usability.
Bachelor or Masters degree in computer science or engineering
10-15 years of industry experience.
Candidates with experience of Javascript , HTML and in addition posses knowledge of Java, Spring, Hibernate, REST, OSGI are highly preferable
Knowledge in networking will be added advantage
