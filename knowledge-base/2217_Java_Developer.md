Position Description

The purpose of this role is to serve as a full stack software developer. The focus of the role is developing web applications and working on other components of Aperio’s software systems. Our web applications are built using Django, so you can expect a lot of Python and JavaScript programming. Aperio practices agile software development and works in two-week sprints. Therefore, this role will work closely with all other members of the Aperio technology team as well as members of our project management team and end users.

Duties and Responsibilities

Provide consistent improvements to Aperio’s codebase and choice of third-party enterprise software components
Write code that is easily understood and maintainable by other team members
Keep up to date with developments in technologies Aperio is using
Use Git (and a flavor of GitFlow) to keep track of software versions
Contribute to overall application design, from the way applications interact with users to the way data is stored in the database
Continuously improve Aperio’s CI/CD practices
Perform other duties as assigned

Required Skills/Experience

Five-plus years’ experience in a similar role
Solid knowledge of programming fundamentals—algorithms, data structures, design patterns, and paradigms
Advanced knowledge of web development, with a deep understanding of the JavaScript ecosystem
Seasoned Python background or related experience with modern object-oriented languages (Java, Scala, etc.)
Facility with building web applications and integrating them with other software systems
Experience in an Amazon Web Services (AWS) ecosystem
Familiarity with relational databases
Strong written and verbal communication skills
Ability to communicate and work effectively, supporting various business departments
Ability to work in fast-paced interdisciplinary environment
