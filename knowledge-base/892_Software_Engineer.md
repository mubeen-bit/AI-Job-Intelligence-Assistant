Job Description
Job Summary:

We are looking for a Software Engineer for our RED Tintri Storage engineering team who will participate in the design, build and deliver of data protection solutions for DDN RED software storage product:
Implement critical distributed storage components including file system network protocols, storage optimization features and high availability services.
Implement heath checking tools definition and implementation providing solutions for data consistency, data replication and media continuous sniff testing.
Responsibilities for this role include but are not limited to:
Drive design discussions, build prototypes and contribute to deliver high quality products;
Design and implement complex and critical distributed storage components including file system network protocols, storage optimization features and high availability services;
Conduct code reviews and improve scalability, stability, reliability and performance of RED product support solutions;
Collaborate with your teammates and integrate a group of passionate developers in an outcome oriented environment;
Adopt Agile practices and support appropriate technical meetings/scrums and message progress/status/concerns;
Providing regular reports on your project progress to team members and supervisors.
Qualifications:
BS/MS/Ph.D in Computer Science, Computer Engineering, Statistics, Mathematics or equivalent degree/experience.
5+ years of experience years of software development experience with file systems, server architectures and distributed systems.
Experience in developing and debugging at system level C/C++, particularly for Linux/UNIX computing environments.
Experience on system deployment on premise or cloud for Enterprise solutions
Understands all or some of IB and high performance Ethernet, tcp and socket programming, libfabrics, virtualisation for datastores, data storage, file systems.
Attention to detail and commitment to high quality deliverables.
Strong team player with good communication skills and should be self-starter.
Excellent time management skills, with the ability to independently prioritize, multitask, and work under deadlines in a fast paced environment.
