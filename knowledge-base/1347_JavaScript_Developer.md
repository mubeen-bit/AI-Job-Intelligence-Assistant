# Job Title: JavaScript Developer

## Job ID: 1347

## Description
We are looking for a Full-stack Javascript Developer to help us build medium to large-scale, high performance web applications. Your primary focus will be the development of all server-side logic, definition and ensuring high performance and responsiveness to requests from the front-end. You will also be responsible for developing front-end elements using various Javascript frameworks like React.js, Angular.js, Node.js. Therefore, hands-on experience on front-end technologies (including HTML, CSS) from ground up is critical as well.

Skill Requirements:
Know-how of frontend technologies such as HTML5, CSS3 (and understanding of pre-processors like SASS/SCSS), JS and jQuery.
Knowledge of JS frameworks (atleast one of the following):
Angular 4/5
Node.js
React.js
Vue.js
Strong (or intermediate) proficiency with web related protocols and architectures (MVC, REST APIs, JSON, HTTP)
Excellent understanding of OOP patterns and methodologies.
Experience with responsive web design and development.
Experience with cross-browser compatibility.
Hands-on experience in frontend Javascript development to at-least ES5/ES6 specification is a plus.
Experience in developing/building SPAs to medium to large scale web applications in Angular, React is a plus.
Understanding of importance and implementation of accessibility and security compliance in web applications is a plus.
Strong customer focused approach, excellent problem solving and analytical skills.
