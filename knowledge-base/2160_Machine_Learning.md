Machine Learning Performance Engineer
AMD is seeking an expert at machine learning with background in frameworks such as Pytorch/TensorFlow, and machine learning workloads. The successful candidate will have a passion for machine learning algorithms, and understand the mapping of the machine learning workloads (such as CNNs, Transformer, BERT, recommendation models) on CPU/GPU architecture. This is a highly visible position with opportunity to work closely with teams across AMD and impact MLPerf optimizations on AMD hardware and software architectures.
You will have the opportunity to:
Define next generation algorithmic and software optimizations for machine learning training by conducting in-depth performance analysis of workloads and presenting the design and implementation choices.
Work with internal AMD teams and external customers to understand and develop software optimizations at machine learning frameworks level such as Pytorch/Tensorflow.
Drive development, product definitions, and customer interactions that lead to the development of AMD best-in-class machine learning platforms.
Develop machine learning software optimizations specific to AMD GPU platforms.
The best applicant will have:
MS or equivalent experience in a field associated with machine learning algorithms and frameworks; candidates with additional experience in architecture would be given preference
Expertise with Pytorch/TensorFlow
Experience with standard machine learning models such as ResNet50, Transformer, SSD, BERT, DLRM and Reinforcement Learning
Experience with performance tools such as nvprof, and rocprof
Familiarity with large scale execution of machine learning models on clusters connected with Ethernet/InfiniBand
