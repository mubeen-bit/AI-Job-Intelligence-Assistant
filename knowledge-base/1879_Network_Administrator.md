# Job Title: Network Administrator

## Job ID: 1879

## Description
Roles and Responsibilities
Installing and configuring CISCO Routers and Switches
Installing and Configuring a Network Installing, Configuring and operates Simple routed LAN & routed WAN Configuring IP, RIP, IGRP, EIGRP, OSPF, Serial, VLAN
Configuration PPP, ISDN
Firewall Implementation, Configure Firewall Fort iGATE
Creating users, groups and setting up policy for a users and groups
Configuration and Troubleshooting of Cisco Switching protocols (RSTP, PVST) Perform data backups and disaster recovery operation.
Analysis of LAN/WAN to determine network performance problems. Provided solutions and documentation
Configuration and Troubleshooting of VLAN, VTP for Cisco switches, IOS upgrading of routers and switches.
Carrying out DR (Disaster Recovery) test for both connectivity and devices for every month
Investigating, diagnosing and resolving all network issues by coordinating with users.
Replacing the network hardware in case of failures and up gradation.
Deploying Cisco Routers and Switches as per the project requirement.
Coordinating with ISP vendors in case of link failure
Network connectivity troubleshooting
Documentation of Known error database and Knowledge Sharing

ITIL knowledge – Added advantage
