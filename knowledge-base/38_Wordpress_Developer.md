# Job Title: Wordpress Developer

## Job ID: 38

## Description
We are on the hunt for a Wordpress developer with 2-4 years of experience who is capable of collaborating with our web designers to match visual designs.
Skills and Qualifications
Prior experience in working with WordPress, Plugin Customization, WordPress + Woo-Commerce, Magento (or Any other PHP open source Framework)
Must have expertise in WordPress theme integration and should be able to work as per client instruction to design page layouts.
Knowledge of other PHP CMS like Magento, Joomla, and CakePHP would be an added advantage.
Good understanding of cross-platform and cross-browser issues, and web performance optimization.
Basic knowledge of the Search Engine Optimization process.
Experience with Reactjs is a plus.
Roles and Responsibilities
Write testable, well designed, and efficient code by using best software development practices and reusable PHP modules to match the latest international web protocols, standards and technologies.
Create website layouts /user interface by following standard HTML/CSS and WordPress practices.
Integrate data from various back-end services and databases.
Be responsible for maintaining, expanding, and scaling various websites.
Stay plugged into emerging technologies and industry trends.
