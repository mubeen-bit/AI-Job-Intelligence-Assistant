## Description
Job Purpose*
Collaborate with project managers, application developers, web designers and clients to plan, design, and deliver innovative web-based solutions using Java tools and frameworks.
Job Duties*
The ideal candidate should be familiar with the Java suite of technologies including working with servlets, Core Java as well as REST API concepts that make the building of web applications easy.
Develop front-end applications to manage content, provide interaction and deliver cross-browser and cross-device content and features
Strong knowledge of Content Management Systems (CMS) such as Adobe Experience Manager, WordPress, and Drupal
Write clean, compliant and reusable code
Methodically test projects against project requirements to ensure high quality, well-tested products
Interact professionally with team members and clients
Bring genuine interest and commitment to learning the latest technological developments in the industry
Skills / Qualifications*
You will collaborate with team members to plan, design, develop, and deliver innovative websites and solutions.

_Technical Skills_
3 years of Java/J2EE development experience
Java experience can be a mix of academic projects, internships and/or professional environment

Experience with Source Control (Git, TFS)
Considerable experience using the JavaScript Frameworks such as NodeJS, jQuery, and Angular
Degree in Computer Science or related field a plus
_Soft Skills _
Communicate effectively and clearly, in writing and orally
Ability to work independently and collaboratively, prioritize tasks, and deliver projects on deadline
