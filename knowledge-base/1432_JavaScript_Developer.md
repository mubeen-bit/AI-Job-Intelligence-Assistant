# Job Title: JavaScript Developer

## Job ID: 1432

## Description
As an Axelerant JavaScript Developer II, you would be designing and implementing the look and feel of websites and related materials by creating sitemaps, wireframes, and visual design comps for internal and client-facing web projects. Additionally, you’ll design for multiple devices and interactions (such as desktops, touch devices like smartphones and tablets, and simpler devices like feature phones).

The JavaScript Developer II at Axelerant has a broad domain grounding and produces quality results for sizeable tasks in a project team. They are comfortable with their preferred domain and frameworks while composing outcomes medium complexity using modern methodologies.

JavaScript Developer II are confident communicators internally and with clients. They are still learning more in-depth on the domain side while gaining confidence in sharing their knowledge to help others. Upon reaching JavaScript Developer II, their project work is fully billable.

The JavaScript Developer II at Axelerant could progress to a Senior Engineer role within three years.

Responsibilities
Demonstrate robust front-end design and development with a passion for pleasing user experiences.
Work with designers to translate designs and wireframes into high-quality code.
Analyze needs plus identify gaps and ambiguities in requirements.
Work with architects and designers to solve small-to-medium features, including analyzing requirements, technical design, development, and launch.
Develop unit and automated integration tests that give the team confidence to deploy to production systems on a predictable cadence.
Be proactive in communication with team members.
Work with scrum team members to review and understand incoming work items and estimate time appropriately, with minimum guidance from mentors as and when required.
Requirements
3+ years of relevant career experience
1+ years of experience using agile methodologies
1+ years of experience using Git source code versioning and Pull Requests
Experience building Single Page Applications using frameworks like Angular, Vue, or React.
Experience in JavaScript profiling towards application performance and code optimization.
Experience in managing your front-end with package managers such as NPM and organization tools like Grunt.
Experience integrating open source and third-party libraries and frameworks into existing systems.
Nice to Have
Experience interacting with RESTful APIs and formats (JSON, XML).
Experience providing technical support or consulting is strongly preferred.
Experience with continuous integration tools like Jenkins, Travis, or Circle CI.
Experience with Node.js and NPM ecosystem.
Familiarity with Progressive Web Application and building offline experiences.
Knowledge of CSS frameworks such as CSS, SASS, LESS, OOCSS, Smacss, BEM, etc.
Knowledge of advanced JavaScript concepts and loopholes. Familiarity with ES2015 and beyond.
Knowledge of front-end tools such as Gulp or Webpack.
Theme building experience for CMS technologies like Drupal or WordPress.
