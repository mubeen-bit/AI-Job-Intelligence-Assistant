# Job Title: Wordpress Developer

## Job ID: 289

## Description
Job Summary:

Key responsibility is to design and develop both front end and back end web development using WordPress which include creating wordpress themes and plugin development.

Job Description
Responsibilities and Accountabilities:
Designing and implementing new themes, plugin and hands on integration knowledge with HTTP REST APIs
Should have good experience or working with advanced custom fields.
Ensuring high performance and availability and managing all technical aspects of CMS.
Helping formulate an effective, responsive design and turning it into a working theme and plugin.
Understanding of entire web development process including design and development.
Tools & Resources required:

Desktop

Job Specifications
Qualification(s):

B.E., M.E.

Experience
Nature of Experience: Strong knowledge in WordPress Development for both Front-end and Back-end, including creating wordpress themes and plugin development.
Length of Experience: 3 - 6 years.
Skill Set & Personality Traits required:
Must have expertise working on plugin development and can develop plugin from scratch.
Good understanding of front end technologies including HTML5, CSS3, Javascript
Strong understanding of PHP back end development.
Able to work on complex type of WordPress project.
Comfortable working in debugging tool like firebug chrome, etc,.
Ability to convert comprehensive layout and wireframes into working HTML
Knowledge of how to interact with RESTful APIs and format
Location: Chennai
Age Group: 25 – 30 years.
