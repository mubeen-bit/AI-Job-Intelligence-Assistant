# Job Title: DevOps Engineer

## Job ID: 1788

## Description
Job Description:

We are looking for a DevOps Engineer to expand and strengthen its exceptional team at our Gurgaon office.

Duties and responsibilities :
Implement best practices for code management, build, deploy, and release across multiple teams/products in CI /CD model
Should be able to address and perform root cause analysis for the technical issues encountered by the project team and to provide effective solutions
Should be able to understand the nature of the application, then design and build an automated deployment toolset and infrastructure
Design, Deploy and Maintain application infrastructure on Cloud platforms
Implement and improve monitoring and alerting
Requirement :
Code management best practices such as branching, merging, and integration strategies with Git, BitBucket, SVN
Management of continuous integration servers like Jenkins, CircleCI, VSTS or TFS and creating Jenkins CI/CD pipelines for Java, LAMP, MEAN and MERN Applications and Mobile Apps
Experience in using any Build tool such as Maven, Gradle, etc
Familiarity with container orchestration services, such as Docker, Kubernetes, ECS, GKS
Administrative proficiency on Unix systems Linux (UbuntuOS, CentOS, or any other Server OS flavor)
Installation, configuration, and performance tuning of App/Web tier (IIS, Apache, Tomcat or JBoss) for different technology stacks (MEAN, MERN, LAMP) on different environments i.e. Windows, Mac, and Linux
Configuration Management experience such as Ansible, Chef, Puppet, or similar
Experience in integration and configuration of APM tools such as Zabbix, NewRelic, DataDog
A working understanding of code and scripts using any language (Bash or Perl, Python or Ruby)
Expert knowledge of database installation, tuning, and replication (MySQL, MSSQL & MongoDB)
Experience of minimum one Cloud platforms i.e. AWS, Azure, or Google Cloud (AWS is preferred)
