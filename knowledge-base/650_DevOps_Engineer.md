Job Details

As a Devops Engineer, you will be involved in providing production support of a highly complex Linux multi-tier infrastructure. You will also take responsibility for the installation, administration & maintenance of our Linux production & development servers.

You need proficiency on:

Data Servers: MySQL, Neo4J & MongoDB Database administration
Web & Application Servers: JBOSS, Apache Tomcat, NodeJS administration
File systems, data backup and disaster recovery for all servers and desktops
High availability monitoring and alerting systems (MRTG / SNMP experience)
Cloud management: Create new nodes, provide new servers and services
xNIX OS updates, configurations changes, user management and access control
System and Database security as well as documenting the configuration of the system
Handling office system and network infrastructure.

Skills & Qualifications:

BE/BTech from a premiere Engineering college
2-4 years of experience in Systems and Database administration
Ability to independently handle daily sysadmin requests as well as performing scheduled system checkups
Knowledge of Linux deployment and daytoday administration
Experience on Terraform, Kubernetes, Docker, Helm, Jenkins, CI/CD, Github
Building and deploying Micro Services on Kubernetes.
Knowledge of Cloud infrastructures will be required (Amazon EC2, VPC)
Experience with Logging, Monitoring and reporting solutions such as Prometheus, Grafana, Kibana (ELK), New Relic etc
Good knowledge of web infrastructure and common paradigms: Memcached, reverse proxies, SSL, CDN
Experience in administering Linux servers including the use of backup solutions, OS level, and application-level security, monitoring and troubleshooting
Functional knowledge of TCP/IP, Firewalls, DMZs, DNS essential
Knowledge of JBoss / Tomcat administration will be preferred
Proficient in installing, administering and automating MySQL and/or MongoDB server databases
Extensive experience automating system tasks and infrastructure using a scripting language (Python, Bash, Shell)
