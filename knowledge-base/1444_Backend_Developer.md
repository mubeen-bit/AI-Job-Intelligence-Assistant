# Job Title: Backend Developer

## Job ID: 1444

## Description
Looking for a Python / Django Intern, who have intermediate to advance level hands-on knowledge on Django 2.x or 3.x. The internship will give the candidate hands on experience on multiple projects which will become live in coming months.
The ideal candidate will be responsible for implementing backend logic and creating RESTful APIs based on project requirements along with optimizing and debugging the code for any software defects. The candidate will work in all phases of the development cycle i.e. from ideation to implementation phase.
Responsibilities
Perform full life-cycle development on Django and Django rest framework
Adhere to agreed upon delivery schedules
Utilizes source control, continuous integration, and unit testing best practices
Work cross-functionally to define, write code for new features and integrate backend APIs
Perform debugging for software defects
Qualifications
Bachelor's degree or equivalent in Computer Science (pursuing or completed)
0 to 1 year experience in developing Django applications
Hands-on knowledge of Django, Django Rest Framework, Django Templates, Pandas library and other Python libraries
